# T3.4 占位符与配置系统

> Sprint: Phase 3 · 状态: 未开始 · 规模: M · 前置: T3.3

## 目标

定义模板占位符集合与替换规范，把散落在各配置文件里的"app 身份信息"收敛到少数几个落点。做完后：模板里 `grep '{{'` 的命中全部在占位符白名单内，实例化后命中为零。

## 背景与动机

总方案 §3 的 new app 流程第一步就是"占位符替换（`{{app-name}}` / `{{basePath}}` / `{{scope}}`）"。占位符集合必须**先于生成器**（Phase 4）定死，生成器和冒烟 CI 都按同一份规范工作。wip 现状里 app 身份信息散落多处（根 package.json、apps/web package.json、next.config fallback、site 配置、README），不收敛则每加一个占位符就要多改 N 处。

## 工作项

1. 定占位符集合（v1 从简，够用就好）：

   | 占位符 | 含义 | 默认值来源 |
   |--------|------|------------|
   | `{{app-name}}` | kebab-case 应用名（目录名、仓库名、包名前缀） | 用户输入，必填 |
   | `{{app-title}}` | 展示标题（首页、`<title>`、RSS） | 默认取 app-name 的人类可读形 |
   | `{{app-desc}}` | 一句话描述 | 默认 "Built with innate-factory" |
   | `{{base-path}}` | 部署子路径（GitHub Pages 场景 `/<repo-name>`） | 默认 `/<app-name>` |
   | `{{scope}}` | npm scope，固定 `@innate`（总方案 §11：scope 现在就定死） | 常量，占位符形式保留是为了 `--in-core` 场景未来切换 |

2. 落点清单（在模板内逐一占位符化）：
   - 根 `package.json`：name / description
   - `apps/web/package.json`：name → `{{app-name}}-web`（按 T3.2 决策项 A）
   - `apps/web/next.config.mjs`：basePath fallback 与 assetPrefix → `{{base-path}}`；顺带把"GITHUB_PAGES 未设则无 basePath"的语义保留
   - site 配置单点（wip 现有站点标题/作者/RSS 描述的所在处——固化时确认，必要时**新建 `apps/web/lib/site-config.ts` 作为唯一身份落点**，layout 与 RSS 从它读）
   - `README.md`（模板自带新 README，标题用 `{{app-title}}`）
   - `.agents/skills/{{app-name}}-dev/` 目录名（T3.6 生成后补替换）
   - deploy workflow 桩（T3.8 生成后补替换）
3. 定替换规范（写给 Phase 4 引擎与冒烟 CI 共同遵守）：
   - 文件名 / 目录名中的 `{{app-name}}` 同样要替换（rename）
   - 二进制文件（png/woff/ico 等）跳过内容替换，但文件名替换照做
   - 实例化完成后 `grep -r '{{' <target>` 必须为零，否则生成失败并列出残留文件
4. 模板内加占位符白名单自检注释（`factory/templates/app-content/TEMPLATE.yaml` 的 placeholders 字段先占位，T3.10 正式化）。

## 产物

占位符规范（本卡终稿）+ 模板内全部落点完成占位符化。

## 验收标准

- [ ] 占位符集合 ≤ 5 个，每个都有明确默认值规则
- [ ] 模板内 `grep -r '{{'` 命中全部在白名单内
- [ ] 手工实例化（sed 替换全部占位符）后 grep 残留为零、build 绿
- [ ] 身份信息落点收敛：`{{app-title}}`/`{{app-desc}}` 在 web 代码内只出现于 site-config 一处

## 风险与注意

- `next.config.mjs` 的 basePath 语义（env 驱动 + fallback）是 static export 站上过生产的逻辑，占位符化时**只换值不换结构**，改动后必须在 GitHub Pages 形态（`GITHUB_PAGES=true`）下也 build 一次。
- `{{scope}}` 是常量却做成占位符，替换引擎要允许"替换为自身值"（`@innate`）——留这个口子是为了 `--in-core` 生成时 `workspace:*` 依赖切换（Phase 4 T4.2 的分支逻辑），不是过度设计。
