# T4.2 实例化引擎（复制 + 占位符替换）

> Sprint: Phase 4 · 状态: 未开始 · 规模: M · 前置: T4.1（接口）· T3.4（规范）

## 目标

实现生成核心：把 `factory/templates/<template>` 变成目标路径下零占位符残留的可构建目录。T3.9 冒烟 CI 完成后切换调用本引擎。

## 背景与动机

这是 factory 唯一的"模板 → 实例"转换点，所有格式纪律（白名单、rename、二进制跳过）在 T3.4 已定，本卡是执行。集中一个引擎意味着：将来 plugin-package / skill 模板（Phase 5）直接复用，不各写各的复制逻辑。

## 工作项

1. 复制：`shutil.copytree`，排除 `.git`（模板本无，双保险）与 `TEMPLATE.yaml`；目标目录非空即拒（防覆盖，T4.1 校验兜底）。
2. 内容替换：按 T3.4 白名单逐文件替换占位符；文本文件按后缀 + 无后缀配置文件（`.npmrc`、`.gitignore`、`.npmignore`）识别；二进制后缀（png/woff/ico/jpg/webp 等）跳过内容替换。
3. 名字替换：文件名 / 目录名含 `{{app-name}}` → rename（关键案例：`.agents/skills/{{app-name}}-dev/`）。
4. `.npmrc` 特例：无占位符，但 `--registry-url` 非默认时改写 registry 行（T3.7）。
5. `--in-core` 分支锚点（v1 不实现，函数内 TODO 注明）：依赖改 `workspace:*`、删 `.npmrc`、落位核心仓 `apps/` 下。
6. 自检：替换完成后 `grep -r '{{' <target>`，非零则**生成失败**，输出残留文件清单（文件 + 行号），并清理现场（除非 `--keep`）。

## 产物

`new_app.py` 的 `instantiate` 步骤（可独立单测）。

## 验收标准

- [ ] 实例化副本 grep 占位符为零；`package.json` name / skill 目录名 / `.npmrc` 全部正确
- [ ] 二进制资产逐字节一致（cmp 校验抽样）
- [ ] 模板里塞一个故意漏网的占位符变体（如 `{{app-name }}` 带空格）→ 引擎报残留并失败（断言真的咬人）
- [ ] 同参数重复生成 → 第二次被拒（目标非空）

## 风险与注意

- 占位符变体（空格、大小写）是静默漏网的高发区：自检 grep 用宽松模式 `'\{\{\s*[\w-]+\s*\}\}'` 抓一切形似物，白名单外的形似物一律视为残留失败——宁可误杀（模板该修）不可放过。
- 替换顺序：先文件内容后文件名 rename（反过来会让内容替换路径失效）。
