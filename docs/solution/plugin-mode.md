# Plugin Mode Solution

> Status: implemented (P0–P1)  
> Related: Content-first refactor (`site-features.ts`), Making routes under `/making/*`

## Goal

Making（Projects / Weekly / Insights / Issues）以及后续扩展模块，不以硬编码导航进入站点，而是通过 **Plugin 注册** 挂到 sidebar / header，页面可用 iframe 或同站路由加载。

## Current State

| Area | Today |
|------|--------|
| Nav | Hardcoded in `sidebar.tsx` + `header.tsx` |
| Making | First-class App Router pages under `app/making/` |
| Feature flags | `lib/site-features.ts` — Making / Cheatsheets / Awesome / Guides **hidden** |
| Iframe precedent | Collections viewer embeds external URLs |

Routes remain buildable; they are just not advertised in the shell.

## Design Principles

1. **Content is core** — Writing / Collections / Feed stay first-party.
2. **Making is a plugin** — same shell, optional registration.
3. **One registry** — sidebar + header read the same plugin list (no dual hardcoding).
4. **Two load modes** — `route` (same-origin Next page) or `iframe` (external / isolated app).
5. **Static-export friendly** — registry is build-time JSON/TS; no runtime plugin marketplace required for v1.

## Plugin Manifest

```ts
// apps/web/lib/plugins/types.ts
export type PluginLoadMode = "route" | "iframe"

export interface PluginNavItem {
  id: string
  label: string
  href: string           // /making/projects or /plugins/making
  icon?: string          // lucide name or key
  order?: number
}

export interface SitePlugin {
  id: string             // "making"
  name: string           // "Making"
  description?: string
  enabled: boolean
  loadMode: PluginLoadMode
  /** For loadMode === "iframe" */
  iframeSrc?: string
  /** Sidebar section + items */
  nav: {
    sectionLabel: string
    items: PluginNavItem[]
  }
  /** Optional homepage bento tile */
  homeTile?: {
    title: string
    description: string
    href: string
  }
}
```

Example Making plugin (re-enable without editing sidebar JSX):

```ts
// apps/web/lib/plugins/registry.ts
import type { SitePlugin } from "./types"

export const plugins: SitePlugin[] = [
  {
    id: "making",
    name: "Making",
    enabled: false, // flip to true when ready
    loadMode: "route",
    nav: {
      sectionLabel: "Making",
      items: [
        { id: "projects", label: "Projects", href: "/making/projects", icon: "folder-git-2", order: 1 },
        { id: "weekly", label: "Weekly", href: "/making/weekly", icon: "calendar", order: 2 },
        { id: "insights", label: "Insights", href: "/making/insights", icon: "lightbulb", order: 3 },
        { id: "issues", label: "Issues", href: "/making/issues", icon: "check-square", order: 4 },
      ],
    },
    homeTile: {
      title: "Making",
      description: "Projects, weekly reports, insights & issues",
      href: "/making",
    },
  },
]
```

## Shell Integration

```
layout / AppShell
  └─ getEnabledPlugins()
       ├─ Header: dropdown categories from plugin.nav
       ├─ Sidebar: collapsible sections from plugin.nav
       └─ Home (optional): bento tiles from plugin.homeTile
```

### Iframe mode

When `loadMode === "iframe"`:

1. Register a catch-all or dedicated page: `app/plugins/[pluginId]/page.tsx`
2. Render `<iframe src={plugin.iframeSrc} sandbox="..." />` full-height in main
3. Nav `href` points to `/plugins/{id}` (or nested `/plugins/{id}/{item}`)

Reuse sandbox pattern from `components/collections/collection-viewer.tsx`.

### Route mode

Keep existing `app/making/**` pages. Plugin only controls **visibility** and **menu registration**.

## Migration Path

| Phase | Work |

| **P1 (done)** | `lib/plugins/registry.ts` + sidebar/header driven by `getEnabledPlugins()` |
| **P2** | Re-enable Making via `siteFeatures.making = true` (no JSX edits) |

| **P4** | Optional: JSON under `data/plugins.json` generated by scripts |

## Acceptance Criteria

- [x] Enabling a plugin adds section + items to sidebar and header without editing those components
- [x] Disabling a plugin removes it from shell; direct URLs may still work
- [x] Making can be `route` or `iframe` via manifest
- [ ] Static export build still succeeds (verify in CI / local build)

## Non-Goals (v1)

- Hot-loading arbitrary third-party JS bundles
- Marketplace / remote plugin CDN
- Per-user plugin preferences
